# Categoria: Prompts para IA

Prompts reutilizáveis para uso com assistentes de IA (personas, prompts mestre, prompts de projeto
pontuais). Arquivos soltos por enquanto, sem curadoria/deduplicação ainda — vários parecem
variações/versões do mesmo prompt (ex.: `PROMPT MESTRE.txt` vs `Assistente Mestre.txt` vs
`Persona_Dev.txt`). Revisar e consolidar quando for reutilizar.
