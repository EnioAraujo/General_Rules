data/hora, consultas de origem para automação). Arquivos soltos por enquanto — sem `REGRAS-*.md`
consolidado ainda.

| Arquivo | Conteúdo |
|---|---|
| `CONSULTA_AUTOMATE_MODIFICADA.txt` / `CONSULTA_PARA_AUTOMAÇÃO_PAUTOMATE.txt` | Consultas de origem adaptadas para uso em flow. |
| `FUNCAO PWR AUTO - DIVERSAS.txt` | Expressões diversas do Power Automate. |
| `FUNCAO PWR AUTO - FORMATAR_DATAHORA_AUTOMATE.txt` | Formatação de data/hora. |
| `RESOLUCAO_PLAN_INFORMATIVO.txt` | Resolução de um plano informativo. |

| `conculta para power automate.txt` | Consulta para automação. |
